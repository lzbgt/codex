# Multi-Agent System

## Quick Start

**Casual Multi-Agent with Dynamic Role Planning**
```bash
codex multi-agent --objective "task" --monitor
```

## Key Features
- **Dynamic Role Planning**: LLM analyzes objective and creates appropriate agent team
- **Casual Human Engagement**: Human can drop in/out without formal joining
- **Session Persistence**: Each agent gets dedicated session with auto-save
- **Web Search Preference**: Agents prefer web search before human referral
